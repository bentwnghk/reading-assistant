CHAPTER 1

1. Introduction & Welcome

What Mr.🆖 ProReader is, who this guide is for, and how to install the app.

Welcome to Mr.🆖 ProReader

Mr.🆖 ProReader is an AI-powered reading-comprehension assistant designed for classrooms and self-study. You can photograph a page of text, upload a PDF, or pull a text from your school's repository, and the platform will instantly produce summaries, simplified versions, mind maps, image visualizations, vocabulary glossaries, comprehension tests, grammar lessons, and gamified practice — all calibrated to the reader's age.

It works in the browser and can be installed as a mobile / desktop app (a Progressive Web App, PWA). Sign-in uses a Google account. Under the hood, every AI feature can be powered by your school's subscription, your own API key, or a free access password — you choose.

Who this guide is for

This manual documents every feature, from first sign-in to advanced teacher dashboards. Most features are available to everyone; a few are reserved for teachers or administrators. Throughout the guide, role-restricted items are clearly flagged:

MarkerMeansWho can use it
studentDefault learner accountAll signed-in users

The four roles Roles are: student (default — every new Google sign-in starts here), teacher (assigned manually by an admin), admin (an email pre-listed by the deployment), and super-admin (an email pre-listed for global control). Admins manage one school; super-admins manage all schools. You will see your role as a colored badge in the top-right user menu.

How to read this guide

  • Numbered tutorials walk you through key first-time flows (sign-in, AI setup, your first reading session).
  • Reference tables list every option, model, and shortcut for quick lookup.
  • Illustrations are faithful recreations of the real interface, not screenshots — colors and layouts match what you will see on screen.
  • An Appendices chapter provides quick-reference tables, troubleshooting, and a glossary.

How the password stays safe (no need to memorize the detail) Your password is never sent in plain text. Each request signs it with the current time using a one-way hash (HMAC-style). 5.5 The SRS algorithm explained

Mr.🆖 ProReader uses the Leitner 5-box system. Each word sits in a "box" (mastery level 0–5). Answering correctly moves it up a box (longer interval until next review); answering incorrectly moves it down. The goal: review hard words often, easy words rarely, until mastered.

C. Troubleshooting / FAQ

ProblemLikely cause & fix
AI features do nothing / errorNo Billing Mode set, or key/password missing. Open Settings → General and complete one of the three setup modes (Chapter 2).
"Limit reached" on image generationDaily visualization quota hit. Free = 1/day, Subscription = 2/day. Resets daily, or switch to Meter mode for unlimited.
Signed out unexpectedlyThe idle timeout (default 60 min) or the 3-day session ceiling was reached. A 1-minute warning toast precedes idle sign-out.
Spinner vanished mid-generation after navigatingNot a bug — generation continues in the background; the loading state lives in the store and survives navigation. Return to the section to see results.
Grammar/test call fell back to another modelBy design — grammar & reading-test calls auto-fall back to a backup model if the primary fails. No action needed.
Settings won't change after editingClick Save at the bottom of Settings. Authenticated users' settings are stored in the DB and reload on each sign-in.
"With Answers" export is greyed outStudents see answers only after completing the test/quiz. Teachers/admins always see them.
Page flashed blank / scrolled to top onceA lazy-loaded component loaded for the first time. It recovers instantly and won't recur in that session.
Shared session missing my answersExpected — sharing strips answers/scores/chat to give recipients a clean copy. Your original is untouched.
iOS extraction stopped mid-wayiOS may suspend long requests; a Screen Wake Lock is used to prevent this. Keep the screen on during extraction.
