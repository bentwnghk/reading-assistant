第 1 章

1. 簡介與歡迎

Mr.🆖 ProReader 是甚麼、本指南的對象，以及如何安裝應用程式。

歡迎使用 Mr.🆖 ProReader

Mr.🆖 ProReader 是一個以人工智能驅動的閱讀理解助手，專為課堂及自學而設。你可以拍攝一頁文字（或上傳 PDF、貼上網址，或從學校的文字庫選取），平台便會即時生成摘要、簡化版本、心智圖、圖像視覺化、生字詞彙表、閱讀理解測驗、文法課程及遊戲化練習——全部根據讀者的年齡自動調校。

它可在瀏覽器中運行，亦可安裝為手機／桌面應用程式（漸進式網頁應用，PWA）。登入使用 Google 帳戶。在底層，每項 AI 功能可由學校訂閱、你自己的 API 金鑰，或免費存取密碼來驅動——由你選擇。

本指南的對象

本手冊涵蓋所有功能，由首次登入到進階教師儀表板。大部分功能人人可用；少數僅限教師或管理員。全手冊中，受角色限制的項目均有清楚標示：

四個角色 角色包括：student 學生（預設——每個新的 Google 登入皆由此開始）、teacher 教師（由管理員手動指派）、admin 管理員（部署時預先登記的電郵），以及 super-admin 超級管理員（預先登記以作全域控制）。管理員管理一間學校；超級管理員管理所有學校。你的角色會在右上角用戶選單中以彩色徽章顯示。

如何閱讀本指南

  • 編號教學帶你走過首次關鍵流程（登入、AI 設定、第一次閱讀）。
  • 參考表格列出每個選項、模型及捷徑以便快速查閱。
  • 插圖是真實介面的忠實重現，並非截圖——顏色與版面與螢幕所見一致。
  • 附錄章節提供快速參考表、疑難排解及詞彙表。
